## Getting Started

### Accessing the System
1. Open your web browser and navigate to the system URL
2. Click "Login" in the top-right corner
3. Enter your credentials:
   - Email address
   - Password
4. Click "Remember Me" if you want to stay logged in
5. Click "Login" button

### First-time Login
1. Click "Register" if you don't have an account
2. Fill in the registration form:
   - Full Name
   - Email Address
   - Password (minimum 8 characters)
   - Confirm Password
3. Click "Register" button
4. Verify your email address through the link sent to your email

### Password Recovery
1. Click "Forgot Password?" on the login page
2. Enter your email address
3. Click "Send Password Reset Link"
4. Check your email and follow the reset instructions

## Production Management

### Managing Machines

#### Adding a New Machine
1. Navigate to "Machines" section
2. Click "Add New Machine"
3. Fill in machine details:
   - Machine Name (e.g., "Carousell 1")
   - Machine Number
4. Click "Save"

#### Viewing Machine Status
1. Go to "Machines" section
2. View list of all machines
3. Click on a machine to see details:
   - Current Status
   - Production History
   - Maintenance Records

### Production Data Entry

#### Creating New Production Record
1. Click "New Production Entry"
2. Select:
   - Machine
   - Date
   - Shift
3. Enter production details:
   - Output Actual
   - TC (Time Cycle)
   - ST (Standard Time)
4. System automatically calculates subtotal
5. Click "Save"

#### Editing Production Data
1. Find the production record
2. Click "Edit"
3. Modify necessary fields
4. Click "Update"

## Stock Take Operations (STO)

### Creating New STO

#### Basic STO Entry
1. Navigate to "STO" section
2. Click "New STO"
3. Fill required fields:
   - Date
   - Operator Name
   - Casting Type
   - Shift
   - STO Time
   - FM (Floor Manager)
4. Enter stock data
5. Click "Save"

#### Managing STO Data
1. View STO list
2. Filter by:
   - Date Range
   - Casting Type
   - Shift
3. Export or print reports as needed

## Reports and Exports

### Available Report Types
1. **Casting Reports**
   - Casting 1 Report
   - Casting 2 Report
   - Combined Casting Report

2. **Production Reports**
   - Daily Production
   - Shift-wise Production
   - Machine Performance

3. **STO Reports**
   - Daily STO Summary
   - Shift-wise Stock Levels
   - Variance Reports

### Generating Reports
1. Go to "Reports" section
2. Select report type
3. Set parameters:
   - Date Range
   - Machine/Casting Selection
   - Shift Selection
4. Click "Generate"
5. Choose export format:
   - Excel
   - PDF
   - CSV

### Scheduling Regular Reports
1. Navigate to "Report Settings"
2. Click "Schedule Report"
3. Configure:
   - Report Type
   - Frequency
   - Recipients
   - Format
4. Click "Save Schedule"
